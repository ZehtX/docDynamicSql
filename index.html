Verificación Previa: Seguridad en Cláusulas WHERE

Antes de documentar las funciones, se realizó la auditoría del archivo db.php para confirmar si las operaciones críticas obligan a incluir una condición WHERE:

Modo 'UPDATE'

Asegurado: La función evalúa empty($options['where']) y retorna false inmediatamente si se omite, impidiendo la modificación accidental de toda la tabla.

Modo 'DELETE_SOFT'

Asegurado: Verifica explícitamente que existan condiciones en 'where' antes de actualizar la fecha de borrado.

Modos 'SELECT' y 'JOIN'

Opcional: El filtro 'where' es optativo. Si no se provee, la consulta devolverá todos los registros.

Modo 'INSERT'

N/A: No aplica el uso de cláusula WHERE.

Funciones de Uso Externo

Estas son las 4 funciones principales diseñadas para ser llamadas desde tus controladores o scripts PHP:

1. read($tabla, $modo, $options)

Función principal para ejecutar cualquier operación SQL centralizada.

read(string $tabla, string $modo, array $options = []);

2. buildOptions(...$args)

Construye el array utilizando el operador variádico ...$args combinado con Named Arguments de PHP 8+.

$options = buildOptions(
    targetColumns: 'id, nombre',
    where: ['estado' => 'activo']
);

3. cleanData($data)

Sanea entradas de texto o arreglos de manera recursiva contra ataques XSS antes de guardar en BD.

$datosLimpios = cleanData($_POST);

4. normalizeBatchData($datosFormulario, $mapa)

Transforma inputs paralelos en arreglos HTML (ej: <input name="nombre[]">) en un formato compatible con inserciones masivas.

$lote = normalizeBatchData($_POST, ['html_campo' => 'columna_bd']);

¿Por qué existe buildOptions()? (Named Arguments)

La función buildOptions(...$args) recibe parámetros variádicos ...$args. Su razón de ser principal es **habilitar el uso de Named Arguments (Argumentos Nombrados)** de PHP 8+. Esto brinda **máxima legibilidad, autocompletado y velocidad de escritura**, evitando tener que escribir corchetes y llaves de arrays asociativos a mano.

❌ A Mano (Sin buildOptions - Verboso) 
// Forma tradicional manual con arrays
$options = [
    'targetColumns' => 'id, nombre',
    'where' => [
        'estado' => 'activo'
    ],
    'limit' => 10
];
✔ Con buildOptions() & Named Arguments 
// Forma limpia, rápida e intuitiva
$options = buildOptions(
    targetColumns: 'id, nombre',
    where: ['estado' => 'activo'],
    limit: 10
);

Modos del Parámetro $modo

Modo Descripción WHERE Obligatorio Retorno
'SELECT' Consulta simple de una sola tabla. No Array Asociativo / false
'JOIN' Consulta relacional entre dos o más tablas. No Array Asociativo / false
'INSERT' Inserción de un solo registro o múltiple (batch). N/A bool (true/false)
'UPDATE' Actualización de registros existentes. Sí bool (true/false)
'DELETE_SOFT' Borrado lógico (asigna timestamp a deleted_at). Sí bool (true/false)

Ejemplos de Código por Modo (Named Arguments)

1. Modo 'SELECT' (Filtro Simple - Sin IN)

Consulta estándar buscando coincidencia exacta mediante argumentos nombrados.

// Construcción con buildOptions usando Named Arguments
$options = buildOptions(
    targetColumns: 'id_usuario, nombre_completo, correo',
    where: [
        'cedula' => 'V-12345678',
        'estado' => 'activo'
    ]
);

$resultado = read('usuarios', 'SELECT', $options);

2. Modo 'SELECT' (Filtro Múltiple - Con IN)

Pasando un array como valor en el filtro where: para generar una cláusula SQL IN (...).

$options = buildOptions(
    targetColumns: 'id_cliente, nombre, limite_credito',
    where: [
        'id_categoria' => [1, 2, 5], // Transforma a: WHERE id_categoria IN (1, 2, 5)
        'estatus' => 'A'
    ],
    limit: 20,
    offset: 0
);

$clientes = read('cliente', 'SELECT', $options);

3. Modo 'JOIN'

Enlaza tablas mediante la opción llamada joins:.

$options = buildOptions(
    targetColumns: 'usuarios.nombre_completo, roles.nombre_rol',
    joins: [
        ['table' => 'roles', 'type' => 'INNER']
    ],
    where: [
        'usuarios.estado' => 'activo'
    ]
);

$usuariosConRol = read('usuarios', 'JOIN', $options);

4. Modo 'INSERT' (Registro Único)

Inserción simple pasando la información en el argumento nombrado data: pre-saneada con cleanData().

// 1. Saneamiento de datos POST
$postLimpio = cleanData($_POST);

// 2. Construcción con Named Arguments
$options = buildOptions(
    data: [
        'nombre' => $postLimpio['nombre'],
        'cedula' => $postLimpio['cedula'],
        'telefono' => $postLimpio['telefono']
    ]
);

$creado = read('cliente', 'INSERT', $options);

5. Modo 'INSERT' (Múltiple / Por Lotes)

Inserción masiva de varias filas procesadas por normalizeBatchData().

// Mapeo entre inputs HTML y columnas BD
$mapaCampos = [
    'txt_producto' => 'nombre_producto',
    'txt_cantidad' => 'cantidad',
    'txt_precio'   => 'precio_unitario'
];

// Convertimos entradas de arreglo paralelo
$loteDetalles = normalizeBatchData(cleanData($_POST), $mapaCampos);

$options = buildOptions(
    data: $loteDetalles
);

$insertado = read('detalle_factura', 'INSERT', $options);

6. Modo 'UPDATE' (Con filtro obligatorio)

Actualiza únicamente asignando data: y la condición obligatoria where:.

$datos = cleanData($_POST);

$options = buildOptions(
    data: [
        'nombre_completo' => $datos['nombre'],
        'telefono'        => $datos['telefono']
    ],
    where: [
        'rif_cedula' => 'V-10987654' // Obligatorio por seguridad
    ]
);

$actualizado = read('cliente', 'UPDATE', $options);

7. Modo 'DELETE_SOFT' (Borrado Lógico)

Marca el registro mediante fecha enviando la condición con where:.

$options = buildOptions(
    where: [
        'id_cliente' => 5 // Obligatorio por seguridad
    ]
);

$borrado = read('cliente', 'DELETE_SOFT', $options);
